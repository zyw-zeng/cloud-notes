## 📌 文档维护说明

### 命名规范
- 文件名格式：`序号-中文名称.md`
- 序号用于排序，便于按逻辑顺序阅读
- 使用中文命名，便于快速识别内容

### 更新原则
1. 新增文档时，按类别添加到合适的序号
2. 重大功能变更时，及时更新相关文档
3. 保持文档的时效性和准确性

### 文档结构
每个文档建议包含：
- 📋 目录
- 🎯 目标/背景
- ✅ 实现方案
- 📝 使用示例
- ⚠️ 注意事项
- 🔍 故障排查

## 🔗 相关资源

### 项目结构
```
cloud-notes/
├── docs/              # 📚 项目文档（本目录）
├── src/
│   ├── main/
│   │   ├── java/     # Java源代码
│   │   └── resources/
│   │       ├── db/migration/  # Flyway数据库迁移脚本
│   │       └── application.yml # 配置文件
│   └── test/         # 测试代码
├── logs/             # 日志文件
└── pom.xml           # Maven配置
```

### 技术栈
- **后端框架**: Spring Boot 4.0.0
- **数据库**: MySQL + JPA/Hibernate
- **缓存**: Redis + Spring Cache
- **安全**: Spring Security + JWT
- **实时通信**: WebSocket
- **数据库迁移**: Flyway
- **API文档**: SpringDoc OpenAPI (Swagger)
- **日志**: Logback
