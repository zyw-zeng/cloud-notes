# 通知系统所需依赖

## 📦 Maven 依赖清单

请确保您的 `pom.xml` 包含以下依赖：

### 1. WebSocket 支持（必需）

```xml
<!-- WebSocket 支持 -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-websocket</artifactId>
</dependency>
```

### 2. 其他已有依赖（请确认）

```xml
<!-- Spring Boot Web -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>

<!-- Spring Data JPA -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>

<!-- 数据库驱动（根据您使用的数据库选择）-->
<!-- MySQL -->
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>

    <groupId>org.springframework.boot</groupId>

```

## 🗄️ 数据库迁移

### 自动创建表（开发环境）

在 `application.yml` 中设置：

```yaml
spring:
  jpa:
    hibernate:
      ddl-auto: update  # 自动创建/更新表结构
    show-sql: true
```

### 手动创建表（生产环境）

```sql
-- 创建通知表
CREATE TABLE IF NOT EXISTS notifications (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL COMMENT '所属用户',
    title VARCHAR(255) NOT NULL COMMENT '通知标题',
    content TEXT COMMENT '通知内容',
    type VARCHAR(50) NOT NULL COMMENT '通知类型',
    related_id BIGINT COMMENT '关联的资源ID',
    related_type VARCHAR(50) COMMENT '关联的资源类型',
    is_read BOOLEAN NOT NULL DEFAULT FALSE COMMENT '是否已读',
    read_at DATETIME COMMENT '已读时间',
    created_at DATETIME NOT NULL COMMENT '创建时间',
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_read (user_id, is_read),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='通知表';
```

## 🔧 常见问题

### Q1: WebSocket 连接 403 错误

**原因**: Security 配置拦截了 WebSocket 端点

**解决**: 在 `SecurityConfig` 中添加：

```java
@Override
public void configure(WebSecurity web) throws Exception {
    web.ignoring().antMatchers("/ws/**");
}
```

### Q2: 无法找到 SimpMessagingTemplate Bean

**原因**: 未添加 WebSocket 依赖

**解决**: 添加 `spring-boot-starter-websocket` 依赖并重新构建

### Q3: 通知表未自动创建

**原因**: JPA 配置问题

**解决**: 
1. 检查 `application.yml` 中的 `ddl-auto` 配置
2. 或手动执行 SQL 创建表
