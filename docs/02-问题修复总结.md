### 问题1：完成任务报错

**根本原因**：
- `cancelPendingRemindersByTodoId()` 是 UPDATE 查询
- 已添加 `@Modifying` 注解，但事务执行顺序有问题

**修复方案**：
```java
@Transactional
public Todo completeTodo(Long id, String username) {
    Todo todo = getTodoAndCheckPermission(id, username);
    
    // ✅ 先取消提醒
    reminderRepository.cancelPendingRemindersByTodoId(id);
    
    // ✅ 再更新任务
    todo.setStatus(Todo.TodoStatus.COMPLETED);
    todo.setCompletedAt(LocalDateTime.now());
    return todoRepository.save(todo);
}
```

- `TodoService.java` (第 148-162 行)

## 📊 数据库变更

### 新增表：notifications

```sql
CREATE TABLE notifications (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    title VARCHAR(255) NOT NULL,
    content TEXT,
    type VARCHAR(50) NOT NULL,
    related_id BIGINT,
    related_type VARCHAR(50),
    is_read BOOLEAN NOT NULL DEFAULT FALSE,
    read_at DATETIME,
    created_at DATETIME NOT NULL,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_read (user_id, is_read),
    INDEX idx_created_at (created_at)
);
```

**说明**：如果设置了 `spring.jpa.hibernate.ddl-auto=update`，表会自动创建。
