## 🗄️ 二、数据库设计

### 2.1 任务表 (todos)

```sql
CREATE TABLE todos (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(255) NOT NULL COMMENT '任务标题',
    description TEXT COMMENT '任务描述',
    
    -- 状态和优先级
    status VARCHAR(20) NOT NULL DEFAULT 'TODO' COMMENT '状态: TODO, IN_PROGRESS, COMPLETED, ARCHIVED',
    priority VARCHAR(20) NOT NULL DEFAULT 'MEDIUM' COMMENT '优先级: HIGH, MEDIUM, LOW',
    
    -- 时间相关
    due_date DATETIME COMMENT '截止日期',
    completed_at DATETIME COMMENT '完成时间',
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL,
    
    -- 关联关系
    user_id BIGINT NOT NULL COMMENT '所属用户',
    category_id BIGINT COMMENT '分类ID（可选）',
    
    -- 其他
    is_important BOOLEAN DEFAULT FALSE COMMENT '是否重要（星标）',
    order_index INT DEFAULT 0 COMMENT '排序索引',
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_user_status (user_id, status),
    INDEX idx_due_date (due_date)
);
```

### 2.2 提醒表 (todo_reminders)

```sql
CREATE TABLE todo_reminders (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    todo_id BIGINT NOT NULL COMMENT '关联的任务',
    
    -- 提醒时间
    remind_at DATETIME NOT NULL COMMENT '提醒时间',
    
    -- 提醒类型
    reminder_type VARCHAR(20) NOT NULL DEFAULT 'ONCE' COMMENT 'ONCE, DAILY, WEEKLY, MONTHLY',
    
    -- 提前提醒
    advance_minutes INT DEFAULT 0 COMMENT '提前多少分钟提醒（0表示准时）',
    
    -- 提醒方式
    notify_method VARCHAR(50) NOT NULL DEFAULT 'IN_APP' COMMENT 'IN_APP, EMAIL, WEBSOCKET',
    
    -- 状态
    is_sent BOOLEAN DEFAULT FALSE COMMENT '是否已发送',
    sent_at DATETIME COMMENT '发送时间',
    is_active BOOLEAN DEFAULT TRUE COMMENT '是否激活',
    
    created_at DATETIME NOT NULL,
    
    FOREIGN KEY (todo_id) REFERENCES todos(id) ON DELETE CASCADE,
    INDEX idx_remind_at (remind_at, is_sent, is_active)
);
```

### 2.3 任务标签关联表 (todo_tags)

```sql
CREATE TABLE todo_tags (
    todo_id BIGINT NOT NULL,
    tag_id BIGINT NOT NULL,
    PRIMARY KEY (todo_id, tag_id),
    FOREIGN KEY (todo_id) REFERENCES todos(id) ON DELETE CASCADE,
    FOREIGN KEY (tag_id) REFERENCES tags(id) ON DELETE CASCADE
);
```

### 2.4 任务分类表 (todo_categories) - 可选

```sql
CREATE TABLE todo_categories (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    color VARCHAR(7) COMMENT '颜色代码，如 #FF5733',
    icon VARCHAR(50) COMMENT '图标名称',
    user_id BIGINT NOT NULL,
    created_at DATETIME NOT NULL,
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    UNIQUE KEY uk_user_name (user_id, name)
);
```

## 🔔 四、提醒功能技术方案

### 4.1 定时扫描方案（推荐）

使用 **Spring Scheduler** 定时扫描待提醒任务：

```java
@Scheduled(fixedRate = 60000) // 每分钟扫描一次
public void checkReminders() {
    // 1. 查询到期且未发送的提醒
    // 2. 发送通知
    // 3. 标记为已发送
    // 4. 处理重复提醒（生成下次提醒）
}
```

**优点**：
- 实现简单
- 可靠性高
- 资源占用低

**缺点**：
- 精度受扫描间隔限制（最多1分钟延迟）

### 4.2 延迟队列方案（高级）

使用 **Redis 延迟队列** 或 **RabbitMQ 延迟队列**：

```java
// 创建提醒时
redisTemplate.opsForZSet().add("reminder:queue", 
    reminderId, reminderTime.getTime());

// 定时消费
@Scheduled(fixedRate = 1000)
public void consumeReminders() {
    // 获取到期的提醒
    // 发送通知
}
```

**优点**：
- 精度高（秒级）
- 分布式友好

**缺点**：
- 需要额外中间件
- 实现复杂度高

### 4.3 通知发送方式

#### 方式 1：站内通知（推荐先实现）
```java
// 保存到通知表
Notification notification = new Notification();
notification.setUserId(userId);
notification.setMessage("您的任务【" + title + "】即将到期");
notificationRepository.save(notification);
```

#### 方式 2：WebSocket 实时推送
```java
// 使用 Spring WebSocket
messagingTemplate.convertAndSendToUser(
    username, 
    "/queue/reminders", 
    reminderMessage
);
```

#### 方式 3：邮件通知
```java
// 使用 Spring Mail
SimpleMailMessage message = new SimpleMailMessage();
message.setTo(userEmail);
message.setSubject("任务提醒");
message.setText("您的任务即将到期...");
mailSender.send(message);
```

## 💡 七、核心业务逻辑

### 7.1 创建任务流程
```
1. 接收任务信息（标题、描述、截止日期等）
2. 验证数据（标题不能为空、日期格式等）
3. 保存任务到数据库
4. 如果设置了提醒时间，创建提醒记录
5. 返回创建的任务
```

### 7.2 提醒触发流程
```
1. 定时任务每分钟扫描提醒表
2. 查询 remind_at <= 当前时间 && is_sent = false 的提醒
3. 遍历提醒列表：
   a. 获取关联的任务和用户
   b. 发送通知（站内/邮件/WebSocket）
   c. 标记提醒为已发送
   d. 如果是重复提醒，计算下次提醒时间并创建新记录
4. 记录日志
```

### 7.3 任务完成流程
```
1. 接收任务 ID
2. 查询任务并验证权限
3. 更新任务状态为 COMPLETED
4. 设置完成时间
5. 取消所有未发送的提醒
6. 更新统计数据（可选）
7. 返回更新后的任务
```
